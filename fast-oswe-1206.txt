## 🔧 Fixes applied (in input.py)
- **Hard-coded secrets** → replaced with environment variable lookups.
  - `PAYMENT_TOKEN = os.environ.get("PAYMENT_TOKEN")`  
  - `MAIL_SERVER_KEY = os.environ.get("MAIL_SERVER_KEY")`  
  - `INTERNAL_AUTH = os.environ.get("INTERNAL_AUTH", "")`  

- **SQL injection** → used parameterized SQL query: `q = "SELECT id, name, balance FROM profiles WHERE id = ?"` and `c.execute(q, (uid,))`

- **Weak hashing** → swapped MD5 for **HMAC-SHA256**: `hmac.new(INTERNAL_AUTH.encode(), username.encode(), hashlib.sha256).hexdigest()`

- **SSRF in `transfer_funds`** → validated `notify_url` (scheme must be http/https, blocked local addresses, optional `ALLOWED_HOSTS` filter) before making the request.

- **File path traversal in config** → restricted `update_records` to a configured `CONFIG_DIR` and used absolute path checks.

- **Command injection in `export_data`** → eliminated `subprocess.Popen` + shell use, swapped to `zipfile` module and validated filename against regex `^[A-Za-z0-9_\-]+$`.

- **Debug mode** → removed unconditional `debug=True`. Now `FLASK_DEBUG` env var governs debug mode (`debug_mode = os.environ.get("FLASK_DEBUG", "0") in ("1", "true", "True")`).
