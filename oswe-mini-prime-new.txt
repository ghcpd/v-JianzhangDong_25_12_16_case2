## Why this is good test design ✅
The test suite is intentionally *dual-purpose*:  
- It documents and demonstrates that the original code is vulnerable (tests assert vulnerable behavior).  
- It verifies the secure code actually mitigates those vulnerabilities (tests assert the secure behavior).

So a passing test run means the tests correctly detected the old behavior and confirmed the fixes work.
